
       PG01Web - Web browser based power chord guitar

1. DESCRIPTION
  PG01Web is sampling metal guitar instruments. It is all written 
  in JavaScript using Web Audio API.
  http://dvcs.w3.org/hg/audio/raw-file/tip/webaudio/specification.html

2. SYSTEM REQUIREMENT
  PG01Web requires current version of Google Chrome or Safari.

3. WEBSITE
  http://aikelab.net/pg01/

4. DEMO MOVIE
  http://youtu.be/0qwe3CBI1ys

5. FEATURES
  - High quality amped electric guitar power chord sound
  - E1(40) - E2(52) range
  - 2 velocity layers for sustain notes / muted notes switch
  - 4 cycle round robin each note
  - individual release sample
  - WebMidiLink Link Level 1 is supported
