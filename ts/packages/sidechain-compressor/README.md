# sidechain-compressor-audio-worklet

A Sidechainable Compressor built on the WebAudio Audio Worklet API

## Original repository

https://github.com/jadujoel/sidechain-compressor-audio-worklet

## Modification in this fork

- Simplify project structure with single package
- Support Wafer protocol (audio input, side-chain input, audio output)

## Quickstart

```bash
pnpm install
pnpm run dev
pnpm run build
```
